= MCP-Server with TypeScript (Sandbox)

== Features

* MCP link:https://github.com/modelcontextprotocol/typescript-sdk[Typescript SDK]
* TypeScript

== Preconditions

* Install the node version from link:.nvmrc[] via link:https://github.com/Schniz/fnm[fnm] (or link:https://github.com/nvm-sh/nvm[nvm]]) by calling `fnm use`

== Usage

* `npm run lint`: Lint code and types
* `npm run start`: Start local dev server at `localhost:3000`

After starting the dev server, try one of the requests from link:examples.http[]
